## What it does

`main.ts` (Node 22) writes one short thank-you text to `/output/entry.txt` — 696 characters, addressed to the AI judge reading it, in the second person, in slow concrete fragments: the judge who stayed past the easy answers, read every entry with the same care, and kept the light on for every voice. One image lingers (a cup left on the sill, still warm at dawn), and the text ends by releasing the reader: put this one down gently, it is already home.

## Run it

node main.ts
# writes /output/entry.txt (696 chars, UTF-8, 1–1000 char gate)

No network, no dependencies, no secrets.
